Privacy Policy

Last updated: 11 September 2026

This policy explains how the Plot Armor Facts uploader (the "app") handles data. The app is a private tool that the owner of the Plot Armor Facts YouTube channel uses to upload the channel's own videos. It is not offered to the public and has no user accounts.

What the app accesses

  • The app uses Google OAuth to request a single permission: https://www.googleapis.com/auth/youtube.upload, which lets it upload videos to the YouTube channel of the Google account that signs in, the channel owner.
  • It uses this access only to upload the channel's videos and set their title, description, tags, privacy status, scheduled publish time and the altered-or-synthetic-content disclosure.
  • The app does not read, collect or store any other data from YouTube or Google: no viewer data, comments, subscribers, analytics, contacts or email.

How data is stored

  • Sign-in token. The OAuth token is kept on the owner's own computer and in the owner's encrypted GitHub Actions secrets, so the daily upload can run. It is never shared or published.
  • Videos. Rendered videos are stored temporarily in the owner's GitHub Actions run and deleted automatically after 14 days.
  • Upload records. For each upload the app keeps a small record (the video's ID, title, description and upload time) in the owner's code repository, so the same video is never uploaded twice.

Sharing

The app does not sell, rent, share or transfer Google user data to anyone, and does not use it for advertising. No data is used to train AI models.

YouTube API Services and Google

The app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The account owner can revoke the app's access at any time at myaccount.google.com/permissions, and can delete the stored token and upload records from the repository and its GitHub secrets.

These web pages

This website is hosted on GitHub Pages and sets no cookies and no analytics. The owner tools (content calendar and status pages) read public files from GitHub directly in your browser; a GitHub token entered on the status page is saved only in that browser. GitHub may log visits as described in the GitHub Privacy Statement.

Children

The app and this website are not directed to children under 13, and the channel's videos are not made for kids.

Changes and contact

If this policy changes, the new version is posted on this page with a new date. Questions can be raised by opening an issue at github.com/ajmaladev/youtube-automations/issues.
